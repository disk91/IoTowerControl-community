## Internationalization key set for front-end

All slugs below are returned in the `message` field of the `ActionResult` error body,
or as success confirmations. They must be translated in each supported language.

### Contact creation (`POST /contacts/1.0/`)

```
"contacts-creation-body-empty"            : "The contact creation request body cannot be empty",
"contacts-creation-name-required"         : "At least a first name or a last name is required",
"contacts-creation-contact-mean-required" : "At least one contact mean (email, phone or push address) is required",
"contacts-creation-email-invalid"         : "The provided email address is not valid",
"contacts-creation-requester-not-found"   : "The requester account could not be found",
"contacts-creation-no-rights"             : "You do not have the required role to create a contact",
"contacts-creation-group-not-allowed"     : "You do not have access to one or more of the requested groups",
```

### Contact update (`PUT /contacts/1.0/{contactId}`)

```
"contacts-update-body-empty"              : "The update request body cannot be empty",
"contacts-update-contact-not-found"       : "The contact to update was not found",
"contacts-update-requester-not-found"     : "The requester account could not be found",
"contacts-update-not-owner"               : "Only the contact owner can perform this update",
"contacts-update-email-invalid"           : "The provided email address is not valid",
"contacts-update-group-not-allowed"       : "You do not have access to one or more of the requested groups",
"contacts-update-failed"                  : "An unexpected error occurred while updating the contact",
```

### Contact deletion (`DELETE /contacts/1.0/{contactId}`)

```
"contacts-delete-contact-not-found"       : "The contact to delete was not found",
"contacts-delete-requester-not-found"     : "The requester account could not be found",
"contacts-delete-not-owner"               : "Only the contact owner or an administrator can delete a contact",
"contacts-delete-no-group-rights"         : "You do not have administrator rights on any group this contact belongs to",
"contacts-delete-failed"                  : "An unexpected error occurred while deleting the contact",
```

### Contact detail (`GET /contacts/1.0/{contactId}`)

```
"contacts-get-contact-not-found"          : "The contact was not found or is not visible to you",
"contacts-get-requester-not-found"        : "The requester account could not be found",
"contacts-get-failed"                     : "An unexpected error occurred while fetching the contact",
```

### Contact list (`GET /contacts/1.0/`)

```
"contacts-list-requester-not-found"       : "The requester account could not be found",
"contacts-list-none-found"                : "No contacts found for this user",
"contacts-list-failed"                    : "An unexpected error occurred while listing contacts",
```

### Internal / entity errors

These slugs originate from lower-level components and are unlikely to reach the end user
under normal conditions. They are logged server-side and may appear in error responses
during infrastructure failures.

```
"contact-unsupported-hashing-algorithm"   : "An internal hashing error occurred, please contact support",
```
